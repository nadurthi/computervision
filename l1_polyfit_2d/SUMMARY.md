
## 3. Fitting method

One linear program, solved with `scipy.optimize.linprog` (HiGHS):

```
min   C/n · ‖λ‖₁ + 10 · norm_largest(t, k)          n = 28, k = floor(0.75 n) = 21 (capped at #equalities)
s.t.  A_eq λ   = log f(x_j) + t                    samples with log f ≥ −9
      A_ineq λ ≤ −9                                samples with log f < −9
      A_out λ  ≤ log N(g; 0, I)                    guard points
```

C is swept over {0.01, 0.1, 25, 100, 250, 300, 500, 800, 1200, 1900, 2500, 3500, 5000, 7500, 10000}. The sweep stops at the first C where the residual at the highest sample reaches 0.01 % of its value, and keeps the previous solution. If every C fails that test, the first solution is kept. This is the rule from the MATLAB original.

## 5. Summary

- **CUT-8 is about 3× more accurate with 4 fewer points** at degree 6 (4.1 % vs 14.9 % uniform and 13.9 % Gauss–Hermite). At each method's best degree it is still about 2× better (3.9 % vs 7.5–7.8 %).
- **Why the grids fail:** a 5-node-per-axis tensor grid has the degree-5 node polynomial ω(x) = Πₖ(x − xₖ). ω(x), xω(x), yω(x) and the same three in y vanish at all 25 nodes, so the 25 × 28 design matrix has rank 22. No degree-6 polynomial fits all 25 samples. The L1-type residual then satisfies 23 equations exactly and puts the misfit on the peak sample (−1.23 log units on the uniform grid, which leaves the fitted peak at about 29 % of the true one).
- **Why CUT-8 works:** it is not a tensor product. Its 21 × 28 design matrix has full row rank (21, condition number about 660), so every sample is fitted exactly and the L1 term only chooses among exact interpolants.
- **Quadrature exactness is not the mechanism.** Gauss–Hermite 5×5 is exact for xⁱyʲ with i, j ≤ 9, and CUT-8 is exact for i + j ≤ 9. Both are exact for the whole degree-6 basis.
- **The grid failure is avoidable.** Use degree < nodes per axis (≤ 4 here), least squares instead of the L1 residual (which halves the grid error), or a non-tensor design.
- **Caveats:** the surface was chosen to show the effect. On a 3-mode Gaussian mixture all three sets reach only 12–14 %, with CUT-8 slightly ahead. On very smooth, near-Gaussian surfaces the 25-point grids are slightly better at high degree. The shared max|x| = 0.85 scaling also puts more CUT-8 points near the center (5 within r < 0.3, against 1 for each grid).
