9 · Checking the port against the MATLAB code

A reproduction that disagrees with a paper is only useful if the reproduction is right. The HJB repository holds the original MATLAB scripts and several saved workspaces from earlier development runs (Gauss–Legendre points, degree-6 dictionary). One of them, HJBcollSol_2D_vanderpoll_c1_lowcontrol.mat (\(Q=25I\), \(R=3\)), ends with CVX status Solved. It stores the collocation points, the final \(D\), \(F\) and constraint matrices, and the coefficients from all 40 policy iterations. Replaying it in Python:

CheckPython vs MATLAB

The earlier Gauss–Legendre runs in the repository also show why the paper moved to CUT points and boundary points. The run with the final cost weights (\(Q=50I\), \(R=5\)) never settled: its coefficients were still moving at iteration 40.

The Python LP differs from the MATLAB code in two harmless ways. It uses HiGHS with split variables instead of CVX, and it skips Algorithm 1's zeroing loop when the first ℓ1 solution already has at most \(N\) nonzeros. Zeroing coefficients that are already zero cannot change an LP optimum, so the result is identical.

10 · Takeaways

  • CUT points keep collocation affordable. A 9th-order CUT rule needs 745 points in 6-D where a 5-per-axis Gauss–Hermite grid needs 15,625, and it grows more slowly than the polynomial dictionary.
  • The ℓ1 program picks the basis for you. When the true value function is sparse in the dictionary, as in spin stabilization, it finds it exactly and the structure of the optimal feedback law (here, linear in ω) comes out of the solution instead of being assumed.
  • Least-degree interpolation is the wrong criterion for HJB. It optimizes the conditioning of the Vandermonde matrix rather than the value function, and on Van der Pol that is enough to lose stability near the domain boundary.
  • Count independent equations, not points. Symmetric point sets combined with odd or even dynamics produce duplicate rows. Checking \(\operatorname{rank}D\) on the columns that can actually be nonzero shows how much freedom the ℓ1 step really has.
  • Validate the closed loop. Compare \(V(\mathbf x_0)\) with the simulated cost of the policy it defines and check the HJB residual off the collocation points, not just convergence of \(\mathbf c\).
