10 · Checking the port against the MATLAB code

A reproduction that disagrees with a paper is only useful if the reproduction is right. The HJB repository holds the original MATLAB scripts and several saved workspaces from earlier development runs (Gauss–Legendre points, degree-6 dictionary). One of them, HJBcollSol_2D_vanderpoll_c1_lowcontrol.mat (\(Q=25I\), \(R=3\)), ends with CVX status Solved. It stores the collocation points, the final \(D\), \(F\) and constraint matrices, and the coefficients from all 40 policy iterations. Replaying it in Python:

CheckPython vs MATLAB
Vandermonde matrix \(A\) (after matching monomial order)max diff 9 × 10⁻¹⁶

The workspace with the paper's exact cost weights (\(Q=50I\), \(R=5\)) is not usable as a reference, because its last CVX solve reports Failed and its stored coefficients violate their own equality constraints. That earlier Gauss–Legendre setup also never converged (its coefficients were still moving at iteration 40), which is presumably why the paper moved to CUT points.

The Python LP differs from the MATLAB code in two harmless ways. It uses HiGHS with split variables instead of CVX, and it skips Algorithm 1's zeroing loop when the first ℓ1 solution already has at most \(N\) nonzeros. Zeroing coefficients that are already zero cannot change an LP optimum, so the result is identical.

11 · What to take from it

  • The two ideas work where their assumptions hold. CUT points make collocation in 6-D affordable (about a thousand points instead of 15,625). The ℓ1 program finds the true value function exactly when that function is sparse in the dictionary, as in the spin example.
  • Count independent equations, not points. Symmetric point sets combined with odd or even dynamics produce duplicate rows. In the Van der Pol case, 29 points gave 14 equations. Check \(\operatorname{rank}D\) on the columns that can actually be nonzero.
  • Validate closed-loop, not coefficient convergence. Every run here converged. The useful diagnostics are \(V(\mathbf x_0)\) against the simulated cost of the policy it defines, the HJB residual off the collocation points, and, in low dimension, the Pontryagin optimum from a few starting states.
  • ℓ1 is a tie-breaker, not a physics prior. When the collocation equations leave freedom, ℓ1 picks the smallest coefficients, not the best controller. A natural fix is to add rows that the policy actually needs, such as more points along the closed-loop flow, or a least-squares term on extra test points.
